# Extensions beyond the SRS

These are recorded for the owner to decide what stays and what belongs in the academic documentation.

| Extension | Purpose | Dependencies and risks | Status |
|---|---|---|---|
| Tourist accounts (register, login, profile, recovery codes, deletion) | Own and reopen plans across devices | Personal data under PDPA 2010: store the minimum (email, display name) | Planned |
| Staff and admin accounts with roles | Individual accountability instead of one shared password | Admin bootstrap secret handling | Planned |
| Guest-plan claim | Keep account-free planning (SRS assumption) while allowing ownership later | Guest link revoked on claim | Planned |
| Multi-day itineraries and timeline view | Real trips span several days | Conflict detection becomes per day | Planned |
| Itinerary export (.ics calendar, print) and read-only sharing | Use the plan outside the system | Share link is a capability: revocable | Planned |
| Journey planner (two-leg) | SRS 1a "more than one transport option" made concrete | Only as good as the transport records | Planned |
| Record history and audit trail | Accountability for published changes | None | Planned |
| Provenance labels | Honest separation of verified and illustrative data | Requires periodic review dates | Planned |
| Auto, Light and Dark themes | Comfort and accessibility | None (exists since AS03 Theme batch) | Partial |
